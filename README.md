## C language implementation of LC3 virtual machine.

Following the instruction from the following blog [Justin Meiners Blog](https://www.jmeiners.com/lc3-vm/), this is an attempt to write LC3 VM in C language

- This is a literal copy paste implementation of the LC3 virtual machine described in the above blog. 

### Building the project 
- To build the project run this command -> `make build`
- To test out the 2048 or Rogue game run -> `./lc3-vm ./2048.obj` or `./lc3-vm ./rogue.obj`
- To clean the build run -> `make clean`
